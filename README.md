# 🌦️ Weather Website

A responsive and animated weather website that allows users to search for a city and view current weather information and forecasts.

## ✨ Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Show weather conditions
- 💧 Display humidity
- 💨 Display wind speed
- 🌧️ Show rain information
- 📅 Display current date and day
- 🌤️ Weather-based images and animations
- 📱 Responsive design for mobile, tablet, and desktop
- 🌍 Real-time weather data using the OpenWeather API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
- VS Code
- Git & GitHub
